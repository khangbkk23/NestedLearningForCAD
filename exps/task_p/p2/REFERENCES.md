# P2 source and mechanism ledger

Read before the P2 scientific lock. These sources motivate the design; their reported performance is not a matched result for this experiment.

- Behrouz et al., Nested Learning / HOPE: <https://arxiv.org/html/2512.24695v1>, especially sections 3, 7 and 8. Paper-defined: coupled optimization contexts, update timescales, self-referential memories, CMS. P2 project mapping: persistent fast predictor, slow query-trained parameters, controller trained through an exact one-step support update. P2 is not a reproduction of HOPE, DGD or CMS, and makes no priority claim over learned optimizers or bilevel meta-learning.
- Behrouz et al., Titans: <https://arxiv.org/html/2501.00663v1>, section 3, equations 8–14. Paper-defined: gradient-based surprise, momentum and learned retention, inner memory optimization with outer learning. P2 uses previous gradient moments as controller context and a bounded learned pull toward slow parameters. It does not reproduce Titans attention or token-wise test-time adaptation. Evaluation never updates on test images.
- Peng et al., VisionHOPE: <https://arxiv.org/abs/2609.33325>; official source <https://github.com/PSRben/VisionHOPE>, commit `98cfb5d6004472a0ba3d212d3cf884393e39c134`, retained in `externals/VisionHOPE` under the user's explicit clone authorization. Inspected `models/srnl.py`, `models/operator.py` and recurrence source. Five initial memories govern content/value/key/rate/retention; four directional spatial scans restore and fuse outputs. The SRNL implementation explicitly resets recurrent trajectories inside each forward and supports first-order gradients. Its within-image state is not persistent cross-task learning by itself. P2 implements its own one-step higher-order PyTorch update, without importing, building or executing the external CUDA extension.
- Deng and Li, Reverse Distillation: <https://openaccess.thecvf.com/content/CVPR2022/html/Deng_Anomaly_Detection_via_Reverse_Distillation_From_One-Class_Embedding_CVPR_2022_paper.html>. A compact teacher-derived embedding and feature residual motivate a bottleneck predictor. P2 uses one frozen ViT layer and a small spatial decoder, not the paper's full multi-scale reverse-distillation architecture. A bottleneck does not guarantee that every defect is rejected.
- Jung et al., ContCore: <https://arxiv.org/abs/2608.15277>, official source <https://github.com/jungyg/ContCore>. Greedy continuation and memory consolidation are prior art for bounded non-neural support retention. P2 does not claim replay or consolidation is novel; it retains the actual P1 reference results without rerunning this benchmark.
- MPFR: <https://www.sciencedirect.com/science/article/pii/S0031320325016097>. Publisher abstract identifies a replay-based normal exemplar approach for continual anomaly detection/segmentation. Full implementation and protocol parity were not established; no numerical comparison or superiority claim is made.
- P1 metric contracts: exact non-interpolated native AP, common FP32 native interpolation and class-stratified whole-image uncertainty. The original bootstrap upper-bound implementation has a documented tie defect; P2 uses the corrected bound, independently checked on synthetic tied-score samples against CPU calculations.

Leakage conclusion: clean ViT tokens already mix pixels globally. Removing a token after extraction does not hide its content from other tokens. P2's 64-dimensional projection has a nonzero nullspace and prevents unrestricted identity reconstruction, but clean center/neighbor inputs retain contextual information. The existing pre-backbone RGB-mask normal cache provides an intervention diagnostic; it does not convert this architecture into hidden-pixel prediction.
