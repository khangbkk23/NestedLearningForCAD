# Verification scope

`pixi run test` runs current v5 core/state/meta tests, visual FP64 oracle/derivatives, CADIC reference/cache/harness, ReplayCAD native scaffold and shipping/transport checks. Use a fresh writable --basetemp if Windows blocks the default Temp directory. Tests are synthetic engineering evidence, not T4 normal pilot or AD performance.

Old v4 calibration/recovery/workflow tests live in archived source bundles. They are not retained as runnable dead workflows in the current tree. The active numerical oracle remains independent.
